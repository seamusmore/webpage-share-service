# webpage-share-service — UI 规范

版本：1.0。状态：新项目可采用的默认基线；导入项目先由维护者登记现行规则。维护者：前端开发。审查：审查员。

本规范随 Git 管理，定义界面视觉、组件状态和响应规则。业务流程与方案依据见 [设计索引](../design/README.md)，技术栈与运行方式见 [工程约定](../engineering/ENGINEERING.md)。已有品牌规范和组件库时，维护者将实际采用的值、来源及适用范围写入本文；重要调整由项目负责人协调确认。纯后端项目可标记为当前不适用。

## 项目采用情况

| 项目 | 初始约定 | 项目实际值与依据 |
| --- | --- | --- |
| 适用界面 | Web 管理与业务界面 | 管理页 `web/pages.html`（登录后页面列表、共享视图）；首页 `web/index.html`（登录入口） |
| 品牌与组件库 | 简洁浅色基线，复用项目已有组件 | 原生 HTML/CSS，无第三方组件库；六套主题变量见 `web/themes/*.css`（classic/light/dark/arknights/endfield/genshin） |
| 样式入口 | 统一维护设计变量与公共组件样式 | `web/pages.html` 页面级内联样式 + `web/themes/<theme>.css` 语义变量；主题偏好经 `/api/theme` 持久化 |
| 主题与设备 | 浅色、桌面及窄屏 | 六套主题（原版/浅色/深色/方舟/终末地/原神）；实测 1440、768、390px，390px 起卡片单列 |

## 颜色与文字

以下为新项目起始值。项目采用后在共享样式入口维护同一份设计变量，按语义引用。

| 语义 | 默认值 | 用途 |
| --- | --- | --- |
| 主色 / 悬停 | `#2563EB` / `#1D4ED8` | 主操作、链接、选中及焦点 |
| 页面 / 面板 | `#F8FAFC` / `#FFFFFF` | 页面背景与内容层级 |
| 正文 / 辅助文字 | `#0F172A` / `#475569` | 内容、标签和说明 |
| 分隔线 / 控件边框 | `#E2E8F0` / `#64748B` | 内容分隔与输入边界 |
| 成功 / 警告 / 错误 | `#15803D` / `#92400E` / `#B91C1C` | 状态反馈，同时提供文字说明 |

- 字体使用系统无衬线字体，中文回退到 PingFang SC 或 Microsoft YaHei；代码和标识符使用等宽字体。
- 正文 16px，辅助文字 14px，页面标题 28px，区块标题 22px；正文行高 1.5。
- 操作文案写明动作及对象，如“保存配置”；图标按钮提供可访问名称。
- 新增主题时登记整套语义变量，并检查所有组件状态、图片背景和文字可读性。

## 间距、布局与响应

- 默认间距序列为 4、8、12、16、24、32px，控件圆角 8px，面板圆角 12px。
- 桌面内容区最大宽度 1280px，页面边距 24px；768px 以下采用适合任务的单列或折叠导航，页面边距 16px。
- 标题、主要操作和滚动正文分区布局；长列表、弹窗和表格拥有明确的滚动范围。文本截断时提供查看完整内容的方式。
- 默认检查 1440px、768px、390px 三档宽度，实际支持范围在“项目采用情况”中登记。触控场景主要控件点击区域以至少 44px 为设计目标。

## 组件与交互状态

| 组件 | 基线约定 | 检查状态 |
| --- | --- | --- |
| 按钮 | 常规高度 40px，水平内边距 16px；每个操作区突出主要动作 | 默认、悬停、焦点、按下、禁用、加载 |
| 输入与选择 | 标签始终可见，错误说明靠近字段；保留用户已填写内容 | 空值、编辑、只读、禁用、校验失败 |
| 列表与表格 | 表头和数据对齐，行操作清晰，长内容在容器内处理 | 加载、空数据、失败、重试、分页、选中 |
| 弹窗 | 标题、正文、操作区分开，正文独立滚动 | 初始焦点、键盘操作、提交中、失败及关闭后的焦点恢复 |
| 反馈 | 明确成功结果或失败原因，给出可执行的下一步 | 成功、警告、错误、权限不足及连接异常 |

提交中防止重复操作，失败时保留草稿及选择状态。危险操作按业务影响提供确认或恢复路径。刷新和异步更新应保持焦点、阅读位置和用户输入。

### 共享视图（需求 #160，任务 #304）

- 入口：管理页右侧书签「共享」，与全部、分类、收藏并列；书签使用按钮元素，选中态同步 `aria-pressed`。
- 共享卡片：显示名称、文件名、来源用户名、首次打开时间；「打开页面」在新窗口打开来源链接；「保存副本」调用 `POST /api/shared/copy`，成功后刷新本人全部列表并保留当前共享视图。
- 状态：加载中、空列表、加载失败（含重试）、来源失效（红色「已失效」徽标，保存副本禁用并以 title 说明原因）。
- 对比度实测（classic 主题）：保存副本启用态文字 14.68:1；禁用态按 0.72 不透明度合成后 5.89:1；失效徽标白字/红底 6.47:1。
- 响应：1440px 三列、768px 两列、390px 单列；390px 下书签条仅覆盖卡片右侧留白，未遮挡按钮。
- 实现提交：753bf40（`web/pages.html`）。

## 可访问性与验证

- 使用语义化控件、可见标签和清晰焦点；关键路径支持键盘操作，状态同时通过文字或图标表达。
- 普通文字对比度至少 4.5:1、大字及必要控件边界至少 3:1 作为设计检查目标，逐项记录实际检查结果。
- 动效服务于状态反馈，并兼顾减少动画的系统偏好。
- 前端开发提交所用规范版本、界面变化及验证证据；审查员核对实现和例外。执行截图及报告保存到项目主目录 reports/tests/，项目主目录使用引擎注入的绝对路径，结论写入任务节点。
