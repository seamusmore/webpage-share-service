# 需求 #160 管理页新增共享书签与保存副本功能

- 状态：已验收关闭（任务 303/304 验收通过并关闭，2026-11-17）
- 来源：thread_id=10142; message_id=11670（用户指令）

## 背景

用户收到他人分享的网页链接后只能在线查看：收藏、下载等操作均只对自己名下的文件开放，共享页面无法收藏、无法下载、更无法转为自己的文件。管理页右侧竖书签目前只有「全部/分类/收藏」，没有展示他人分享内容的入口；且系统现状没有任何分享关系记录——分享只是复制页面链接，接收方系统中无痕迹。目标：他人分享给我的网页集中出现在「共享」标签，并支持保存副本转为自己名下的网页文件，之后可正常下载/改名/删除。

## 范围

- 包含：①管理页右侧竖书签新增「共享」标签，与全部/分类/收藏并列；②共享标签筛选展示他人分享给我的网页；③每条共享网页提供「保存副本」，把文件内容复制到自己租户存储并建立自己名下的文件记录，保存后可下载/改名（文件名与显示名）/删除；④新增分享关系记录机制及数据表。
- 范围外：不改动现有分享链接格式与分享入口；不做跨租户编辑、公开（免登录）分享、批量保存。

## 验收标准

1. 登录管理页，右侧竖书签出现「共享」标签，与全部/分类/收藏并列；
2. 用他人分享链接（他人名下页面）在本人登录态下打开后，该页面自动出现在本人「共享」标签列表，展示显示名且不混入本人「全部」列表；
3. 同一页面重复打开，共享列表不出现重复条目；
4. 「保存副本」后副本出现在本人「全部」列表，文件内容与来源一致，可下载、可改名（含显示名）、可删除；
5. 副本文件名冲突时有明确且可预期的处理（自动重命名或明确报错）；
6. 来源文件删除或租户失效时共享条目有明确失效提示或合理隐藏；未登录访问分享链接仍重定向登录，登录用户只能看到自己的共享列表。
