# 需求 #161 修复租户页面路由 filename 路径穿越漏洞

- 状态：已验收关闭（任务 305 验收通过并关闭，2026-11-17）
- 来源：thread_id=0; message_id=11675（用户指令）

## 背景

需求#160 后端任务 303 审查发现范围外高危问题（既有代码，非本次引入）：auth-server.js 租户页面路由（约 1467-1498 行）将 URL 解码后的 filename 直接 path.join(tenant.storage_path, filename) 拼接读取，未防穿越。已登录用户可用 ../（含 URL 编码变体）读取 storage_path 之外任意服务器文件。对比同文件 themes 分支（1444-1447 行）已有 resolve+startsWith 白名单校验，租户页面分支缺失同等防护。

## 范围

- 包含：①为 auth-server.js 租户页面文件读取（1492 行）加防穿越校验，越界返回 404；②排查同文件其他 filename 直拼读取点（318、1045、1102、1103、1171、1223、1353 行等处），凡 filename 来自外部输入且缺校验的一并加固；③补穿越攻击自动化回归用例（含 %2e%2e%2f、反斜杠等变体）。
- 范围外：不改动业务功能；不处理 #160 遗留事项。

## 验收标准

1. 穿越请求（../、%2e%2e%2f、..%5c、%2e%2e%5c、双重编码变体）返回 404，不泄露 storage_path 之外内容；
2. 正常访问租户页面及共享记录回归全绿（test_traversal 16 项 + test_shared 23 项）；
3. 排查清单每个 filename 直拼点均有结论（已加固或确认不可达）。
